# Portfolio

Amogh Skanda Suresh's engineering work and background, presented for internship reviewers.

## Language

**Professional case study**:
A description of work Amogh contributed to at an employer, with his contribution distinguished from the team's work. A case study does not imply the employer's source code is public.

**Conceptual workflow**:
A public illustration of general methods and contributions. It explains a workstream without reproducing an employer's internal architecture, configuration, data, or source material.

**Public project**:
A project with a publicly accessible source repository. Public availability does not imply the project is finished.

**Building now**:
Work Amogh is actively developing, with current capabilities distinguished from intended next milestones.

**Planned work**:
An intention to build something. It is presented separately from implemented capabilities and completed achievements.

**Synthetic fixture**:
A deliberately constructed scenario used to illustrate a failure and its handling. It is not a recorded model trial or benchmark result.

**Recovery trace**:
An ordered record of observations, attempted actions, and resulting state changes during failure handling.

**Verified outcome**:
Task completion established from the resulting application state and task requirements, independently of an agent's completion claim.
